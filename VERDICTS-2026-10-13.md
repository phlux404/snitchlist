# SnitchScan verdicts — first report (2026-10-13)

Two flagged unknowns from the first daily SnitchScan report, triaged and
closed on 2026-10-14. Both classifications are now in the database
(index.html + tools/snitchscan.py, mirrored to the live scanner), so
future reports file them on sight instead of flagging them as unknown.

## firebaselogging-pa.googleapis.com

- **Source:** Google Firebase — the production logging endpoint
  (`-pa`) of the Firebase SDK's logging pipeline. Any app that ships
  the Firebase SDK can emit traffic here.
- **Data carried:** app event logs and diagnostics to Google —
  Firebase-style telemetry (app activity, device/app identifiers,
  performance and error data). Exactly the class of traffic this
  project exists to catch.
- **Why it was flagged:** the database already knew
  `firebaselogging.googleapis.com`, but lookups match on label
  boundaries, so the `-pa` host did not inherit the parent entry
  and surfaced as an unknown matching the Firebase SDK pattern.
- **Verdict: BLOCK.** Already on the NextDNS profile denylist;
  verified still blocked in live logs on 2026-10-14. Blocking costs
  nothing in use — it severs app telemetry, not app function.
- **Database:** added as its own entry — Google / analytics.

## shortwave.facebook.com

- **Source:** Meta's speech infrastructure — the endpoint Muse's
  voice dictation (speech-to-text) talks to on this setup.
- **Data carried:** dictated audio for transcription and the speech
  service's session traffic. The user's own functional traffic,
  produced by a feature the user deliberately uses — not a third
  party quietly phoning home.
- **Why it was flagged:** the entropy heuristic (3.57 bits against a
  3.5 threshold) — the known false-positive shape for short,
  service-style hostnames.
- **Verdict: KEEP.** Allowed in NextDNS; verified resolving normally
  in live logs on 2026-10-14. Blocking it would break voice
  dictation to Muse.
- **Database:** added as Meta / functional, alongside the existing
  Meta infrastructure entries.
- **Verified by live test (2026-10-15):** the domain was temporarily
  blocklisted in NextDNS as a controlled experiment. After one initial
  attempt passed on a cached DNS answer, Muse's in-app voice
  dictation failed outright (the dictation interface would not open),
  while typed input and an unrelated on-device speech-to-text app
  kept working. After the block was removed, dictation recovered (a
  phone restart was needed to clear the wedged client state).
  Verdict confirmed by experiment, not inference alone: KEEP.

## Method note

Verdicts were decided from the report's evidence plus live NextDNS
log checks (blocked vs. resolving), not from the domain names alone.
Per the project's standing rule, no log details or identifiers are
published here — counts and timestamps stay on the local systems.
